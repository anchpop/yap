<div class="mw-heading mw-heading4"><h4 id="Adjective">Adjective</h4><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%E3%81%84%E3%81%84&amp;action=edit&amp;section=5" title="Edit section: Adjective"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p><span class="headword-line"><strong class="Jpan headword" lang="ja">いい</strong> <a href="/wiki/Wiktionary:Japanese_transliteration" title="Wiktionary:Japanese transliteration">•</a> (<span class="headword-tr tr" dir="ltr"><span class="Latn" lang="ja"><a href="/wiki/ii#Japanese" title="ii">ii</a></span></span>)&#160;<i><abbr title="-i (type I) inflection">-i</abbr></i> (<i>adverbial</i> <b class="Jpan" lang="ja"><a href="/wiki/%E3%82%88%E3%81%8F#Japanese" title="よく">よく</a></b> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr">yoku</span><span class="mention-gloss-paren annotation-paren">)</span>)</span>
</p>
<ol><li><span class="usage-label-sense"><span class="ib-brac label-brac">(</span><span class="ib-content label-content"><a href="/wiki/Appendix:Glossary#colloquial" title="Appendix:Glossary">colloquial</a><span class="ib-comma label-comma">,</span>&#32;<a href="/wiki/Appendix:Glossary#informal" title="Appendix:Glossary">informal</a></span><span class="ib-brac label-brac">)</span></span> <a href="/wiki/good" title="good">good</a></li>
<li><span class="usage-label-sense"><span class="ib-brac label-brac">(</span><span class="ib-content label-content"><a href="/wiki/Appendix:Glossary#colloquial" title="Appendix:Glossary">colloquial</a><span class="ib-comma label-comma">,</span>&#32;predicative only</span><span class="ib-brac label-brac">)</span></span> <a href="/wiki/enough" title="enough">enough</a>, not <a href="/wiki/wanted" title="wanted">wanted</a> <a href="/wiki/any" title="any">any</a> <a href="/wiki/more" title="more">more</a>

<div class="mw-heading mw-heading5"><h5 id="Usage_notes">Usage notes</h5><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%E3%81%84%E3%81%84&amp;action=edit&amp;section=6" title="Edit section: Usage notes"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>
<ul><li>Most often written in this form. The kanji spelling <span class="Jpan" lang="ja"><a href="/wiki/%E8%89%AF%E3%81%84#Japanese" title="良い">良い</a></span> is generally reserved for more <a href="/wiki/formal" title="formal">formal</a> writing.</li>
<li>This form does not <a href="/wiki/inflect" title="inflect">inflect</a> in Standard Japanese — it is only used in the <i class="Jpan mention" lang="ja"><a href="/wiki/%E7%B5%82%E6%AD%A2%E5%BD%A2#Japanese" title="終止形">終止形</a></i> <span class="mention-gloss-paren annotation-paren">(</span><span class="mention-tr tr">shūshikei</span>, <span class="mention-gloss-double-quote">“</span><span class="mention-gloss">terminal form</span><span class="mention-gloss-double-quote">”</span><span class="mention-gloss-paren annotation-paren">)</span> and <i class="Jpan mention" lang="ja"><a href="/wiki/%E9%80%A3%E4%BD%93%E5%BD%A2#Japanese" title="連体形">連体形</a></i> <span class="mention-gloss-paren annotation-paren">(</span><span class="mention-tr tr">rentaikei</span>, <span class="mention-gloss-double-quote">“</span><span class="mention-gloss">attributive form</span><span class="mention-gloss-double-quote">”</span><span class="mention-gloss-paren annotation-paren">)</span> of <span class="Jpan" lang="ja">いい</span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>ii</i></span><span class="mention-gloss-paren annotation-paren">)</span>. All other grammatical forms are based on <span class="Jpan" lang="ja"><a href="/wiki/%E8%89%AF%E3%81%84#Japanese" title="良い">よい</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>yoi</i></span><span class="mention-gloss-paren annotation-paren">)</span>.</li>
<li>However, <span class="Jpan" lang="ja"><a href="/wiki/%E3%81%84%E3%81%8B%E3%81%A3%E3%81%9F#Japanese" title="いかった">いかった</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>ikatta</i></span><span class="mention-gloss-paren annotation-paren">)</span> is used dialectally, in <a href="https://en.wikipedia.org/wiki/Niigata" class="extiw" title="w:Niigata">Niigata</a> and (often with intervocalic voicing as <span class="Jpan" lang="ja"><a href="/w/index.php?title=%E3%81%84%E3%81%8C%E3%81%A3%E3%81%9F&amp;action=edit&amp;redlink=1" class="new" title="いがった (page does not exist)">いがった</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>igatta</i></span><span class="mention-gloss-paren annotation-paren">)</span>) in <a href="https://en.wikipedia.org/wiki/T%C5%8Dhoku" class="extiw" title="w:Tōhoku">Tōhoku</a>.</li>
<li>In ironic usage meaning “<a href="/wiki/very" title="very">very</a> <a href="/wiki/bad" title="bad">bad</a>” or “<a href="/wiki/embarrassing" title="embarrassing">embarrassing</a>”, this form is preferred over <span class="Jpan" lang="ja"><a href="/wiki/%E8%89%AF%E3%81%84#Japanese" title="良い">よい</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>yoi</i></span><span class="mention-gloss-paren annotation-paren">)</span>.</li></ul>
