<div class="mw-heading mw-heading3"><h3 id="Etymology">Etymology</h3><span class="mw-editsection"><span class="mw-editsection-bracket">[</span><a href="/w/index.php?title=%E8%A8%80%E3%81%86&amp;action=edit&amp;section=2" title="Edit section: Etymology"><span>edit</span></a><span class="mw-editsection-bracket">]</span></span></div>
<p><span class="IPA nowrap">/ipu/</span> → <span class="IPA nowrap">/iɸu/</span> → <span class="IPA nowrap">/*iwu/</span> → <span class="IPA nowrap">/iu/</span> → <span class="IPA nowrap">/juː/</span>
</p><p>From <span class="etyl"><a href="https://en.wikipedia.org/wiki/Old_Japanese" class="extiw" title="w:Old Japanese">Old Japanese</a></span>,<sup id="cite&#95;ref-KDJ&#95;1-0" class="reference"><a href="#cite_note-KDJ-1"><span class="cite-bracket">&#91;</span>1<span class="cite-bracket">&#93;</span></a></sup> from <span class="etyl"><a href="https://en.wikipedia.org/wiki/Proto-Japonic_language" class="extiw" title="w:Proto-Japonic language">Proto-Japonic</a></span> <i class="Latn mention" lang="jpx-pro"><a href="/wiki/Reconstruction:Proto-Japonic/ipu" class="mw-redirect" title="Reconstruction:Proto-Japonic/ipu">&#42;ipu</a></i>.
</p><p>Medial <span class="IPA nowrap">/p/</span> regularly changed from <span class="IPA nowrap">[p]</span> → <span class="IPA nowrap">[ɸ]</span> → <span class="IPA nowrap">[w]</span>. Japanese never distinguished between <span class="IPA nowrap">/wu/</span> and <span class="IPA nowrap">/u/</span>, so that automatically becomes <span class="IPA nowrap">[u]</span>. The <span class="IPA nowrap">/w/</span> only surfaces in the negative form of <i>i<b>w</b>anai</i>, where the phoneme sequence <span class="IPA nowrap">/wa/</span> exists. Surface forms <span class="IPA nowrap">/iwimasu/</span> and <span class="IPA nowrap">/iwemasu/</span> automatically became <span class="IPA nowrap">/iimasu/</span> and <span class="IPA nowrap">/iemasu/</span> since Japanese no longer distinguishes <span class="IPA nowrap">/wi, we/</span> from <span class="IPA nowrap">/i, e/</span>.
</p>

<p>As a transitive verb, this can take the usual <a href="/wiki/accusative" title="accusative">accusative</a> <a href="/wiki/particle" title="particle">particle</a> <span class="Jpan" lang="ja"><a href="/wiki/%E3%82%92#Japanese" title="を">を</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>o</i></span><span class="mention-gloss-paren annotation-paren">)</span> after the object of the verb. However, it is much more common to see this with the <a href="/wiki/quotative" title="quotative">quotative</a> particle <span class="Jpan" lang="ja"><a href="/wiki/%E3%81%A8#Japanese" title="と">と</a></span> <span class="mention-gloss-paren annotation-paren">(</span><span class="tr"><i>to</i></span><span class="mention-gloss-paren annotation-paren">)</span> instead.
